## 键盘常量

### 字母
`K_a` … `K_z`——`studio.K_a` 就是 A 键，大小写无所谓。所有常量都以 `studio.<名称>` 的形式提供。

### 数字
`K_0` … `K_9`（主键盘数字行）。

### 功能键
`K_F1` … `K_F15`。

### 方向键
`K_UP`、`K_DOWN`、`K_LEFT`、`K_RIGHT`。

### 编辑键
`K_BACKSPACE`、`K_TAB`、`K_RETURN`、`K_DELETE`、`K_INSERT`、`K_ESCAPE`、`K_SPACE`、`K_CLEAR`。

### 导航键
`K_HOME`、`K_END`、`K_PAGEUP`、`K_PAGEDOWN`。

### 小键盘
`K_KP0` … `K_KP9`、`K_KP_PERIOD`、`K_KP_DIVIDE`、`K_KP_MULTIPLY`、`K_KP_MINUS`、`K_KP_PLUS`、`K_KP_ENTER`、`K_KP_EQUALS`。

### 修饰键
`K_LSHIFT`、`K_RSHIFT`、`K_LCTRL`、`K_RCTRL`、`K_LALT`、`K_RALT`、`K_LMETA`、`K_RMETA`、`K_LSUPER`、`K_RSUPER`、`K_CAPSLOCK`、`K_NUMLOCK`、`K_SCROLLOCK`、`K_MODE`。

### 符号键
`K_EXCLAIM`、`K_QUOTEDBL`、`K_HASH`、`K_DOLLAR`、`K_AMPERSAND`、`K_QUOTE`、`K_LEFTPAREN`、`K_RIGHTPAREN`、`K_ASTERISK`、`K_PLUS`、`K_COMMA`、`K_MINUS`、`K_PERIOD`、`K_SLASH`、`K_COLON`、`K_SEMICOLON`、`K_LESS`、`K_EQUALS`、`K_GREATER`、`K_QUESTION`、`K_AT`、`K_LEFTBRACKET`、`K_BACKSLASH`、`K_RIGHTBRACKET`、`K_CARET`、`K_UNDERSCORE`、`K_BACKQUOTE`。

### 系统键
`K_PAUSE`、`K_PRINT`、`K_SYSREQ`、`K_BREAK`、`K_MENU`、`K_HELP`、`K_POWER`、`K_EURO`、`K_AC_BACK`。

## 修饰键

### `KMOD_SHIFT`、`KMOD_LSHIFT`、`KMOD_RSHIFT`
Shift（任意 / 左 / 右）。

### `KMOD_CTRL`、`KMOD_LCTRL`、`KMOD_RCTRL`
Ctrl。

### `KMOD_ALT`、`KMOD_LALT`、`KMOD_RALT`
Alt。

### `KMOD_META`、`KMOD_LMETA`、`KMOD_RMETA`
Meta / Cmd / Windows 键。

### `KMOD_CAPS`、`KMOD_NUM`、`KMOD_MODE`
大写锁定、数字锁定、AltGr。

### `KMOD_NONE`
没有按下修饰键。

## 鼠标按键

### `1`
左键。

### `2`
中键（滚轮按下）。

### `3`
右键。

### `4`
滚轮向上。

### `5`
滚轮向下。
