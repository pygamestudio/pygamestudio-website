---
title: 音频播放器
---

**音频播放器（Audio Player）** 可以让你在编辑器里直接试听项目中的音频。在[资源管理器](/zh-cn/editor_introduction/asset/)中双击音频文件，它就会在窗口底部打开。

![音频播放器](/images/doc/audio_editor_window.png)

## 工具栏

| 控件 | 作用 |
| --- | --- |
| **打开音频文件** | 打开文件对话框（支持 `.wav`、`.mp3`、`.ogg`、`.flac`、`.aif`、`.aiff`、`.m4a`）。 注：`m4a`音频文件目前无法被编辑。|
| **上一首 / 下一首** | 在项目文件夹中的音频文件之间切换。 |
| **播放 / 暂停** | 开始或暂停播放，按钮图标随播放状态变化。 |
| **停止** | 停止播放并回到开头。 |
