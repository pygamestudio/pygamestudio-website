---
title: 创建对象
---

对象是场景的基本组成单位：图形、图片、文字、按钮……你在游戏窗口中看到的一切都是对象。本文将介绍如何添加对象以及设置对象属性。

## 添加对象

对象都在编辑器左上角的**层级管理器**窗口中创建。可在层级窗口中**右键**或者点击左上角的**添加按钮**，然后在菜单中选择一种对象即可。

![添加菜单](/images/doc/create_an_object_add_menu.png)

新对象会插入到所选对象的下面并自动选中，以默认坐标 (20, 20) 显示在场景中，右侧的属性检查器窗口中会同步显示它的属性。

![新建对象](/images/doc/create_an_object_added.png)

## 重命名

在添加后可以给对象起一个有意义的名称，例如 `Player (玩家)`、`Enemy (敌人)`、`Ground (地面)`，这样之后在层级和属性窗口中会好找得多。重命名方式有以下两种：

- 在层级窗口中右键对象选择**重命名**
- 在属性窗口的 **名称** 一栏中输入新名称

![重命名](/images/doc/rename_an_object_added.png)


## 改变对象位置和其他属性

在场景中点击对象后，按住左上角的**拖拽小控件**即可拖动对象改变其坐标。当它与其它对象（或画布本身）的边缘、中心对齐时，会出现品红色的**智能参考线**，让对象吸附成整齐的行列。

或者我们也可以**属性窗口**中改变`位置`属性，从而改变对象在画布上的坐标。

![改变位置](/images/doc/move_an_object_added.png)

:::note
子对象的位置是相对于父对象的，因此移动父对象时子对象会一起移动。
:::

除了`位置`属性，对象的其他属性也都可以在**属性窗口**中修改，比如要旋转对象，我们只需要设置`角度`属性即可。

![旋转对象](/images/doc/rotate_an_object_added.png)
