---
title: 对象
description: 所有场景对象类型、类型标识，以及列出各自属性、方法和事件的页面。
---

| 对象 | 类型标识 | 说明 |
| --- | --- | --- |
| [画布](/zh-cn/api/objects/canvas/) | `CANVAS` | 场景的根对象；移动它就移动整个场景。 |
| [矩形](/zh-cn/api/objects/rect/) | `RECT` | 可设置圆角的填充矩形。 |
| [椭圆](/zh-cn/api/objects/ellipse/) | `ELLIPSE` | 椭圆（宽高相等即圆形）。 |
| [直线](/zh-cn/api/objects/line/) | `LINE` | 两点之间的线段。 |
| [多边形](/zh-cn/api/objects/polygon/) | `POLYGON` | 由顶点列表构成的自由形状。 |
| [图像](/zh-cn/api/objects/image/) | `IMAGE` | 来自资源面板的图片，可着色。 |
| [文本](/zh-cn/api/objects/text/) | `TEXT` | 使用字体绘制的文字。 |
| [按钮](/zh-cn/api/objects/button/) | `BUTTON` | 可点击的矩形或图片。 |
| [文本输入框](/zh-cn/api/objects/text_input/) | `TEXT_INPUT` | 可编辑的输入框。 |
| [进度条](/zh-cn/api/objects/progress_bar/) | `PROGRESS_BAR` | 0–100% 指示条。 |
| [滑块](/zh-cn/api/objects/slider/) | `SLIDER` | 可拖动的数值控件。 |
| [粒子](/zh-cn/api/objects/particle/) | `PARTICLE` | 火花、烟雾、爆炸效果的发射器。 |
| [序列帧](/zh-cn/api/objects/frame_sequence/) | `FRAME_SEQUENCE` | 逐张图片播放的动画。 |
| [瓦片地图](/zh-cn/api/objects/tile_map/) | `TILE_MAP` | 用图块拼出的关卡。 |
