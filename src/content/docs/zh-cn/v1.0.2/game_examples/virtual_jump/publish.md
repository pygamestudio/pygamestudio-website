## 在编辑器里试玩

按 **Ctrl + R**（或点击工具栏的运行按钮）以独立窗口启动游戏；[控制台](/zh-cn/editor_introduction/console/)会显示脚本里 `print` 的输出，调试时很好用——案例脚本里每次加分、中弹、重开都有日志。

## 打包成网页版

菜单**项目 → 打包**，切到**网页应用**页签：

1. 填好应用名称（页面标题），其余默认即可；
2. 点**打包**，完成后点**在浏览器中运行**立即试玩；
3. 产物是 `build/Web/` 文件夹——把整个文件夹发给朋友（或上传到任意静态网站），用浏览器打开就能玩，不需要安装任何东西。

网页版有几条**浏览器规则**，遇到时不用慌：

- **第一次点击或按键之后才会出声**（浏览器禁止未经交互的自动播放）；画面本身会自动开始；
- 游戏画面与**显示器刷新率对齐**，滚动更顺滑；
- **切到别的标签页时游戏自动暂停**，回来自动继续；
- 音乐与音效由浏览器直接解码播放，MP3 / OGG / WAV 都能用。

## 打包成桌面版

同一个打包窗口的**桌面应用**页签可以把游戏做成当前系统的独立可执行文件（Windows / macOS / Linux），打包完成后点**运行游戏**直接验收。桌面版与编辑器里试玩的效果完全一致。

## 继续改进

- 改手感：`player.py` 顶部的速度、重力、跳跃、冲刺常量；
- 加难度：`game_manager.py` 里的子弹/水果间隔、速度范围；
- 换素材：把 `image/`、`audio/` 里的文件替换成自己的（保持文件名就不用改代码）；
- 换玩法：看看[全局 API](/zh-cn/api/global/)与[对象 API](/zh-cn/api/objects/)，把分数改成计时、把水果换成金币都可以。
