---
title: 层级管理器
---

左上角的 **层级管理器（Hierarchy）** 以树形层级结构列出当前场景中的所有对象，是创建、选择、重命名、调整父子关系和删除对象的地方。

![层级管理器](/images/doc/hierarchy.png)

## 对象层级

层级根节点是 **画布 (Canvas)** —— 即场景本身，其它对象都是画布的子（孙）节点：

- 隐藏父对象时子对象也会一并隐藏；
- **子对象的位置相对于父对象**，因此移动父对象时子对象会一起移动；
- 层级中的顺序就是绘制顺序，越靠下的对象（层级越大）绘制在越上层，也就是说层级大的对象会遮挡住层级小的对象。

## 工具栏

| 控件 | 作用 |
| --- | --- |
| **添加** | 打开对象类型菜单：图形、UI、特效、动画、世界。 |
| **展开 / 折叠全部** | 一次性展开或折叠选中的层级。 |
| **搜索** | 按对象名称或 UUID 进行搜索。 |
| **分离** | 让层级管理器变成独立窗口，再次点击按钮或关闭独立窗口可停靠回来。 |

## 常用操作

- **添加对象** —— 点击 **添加** 按钮，或在层级中右键后从 **添加** 菜单中选一项。新对象会创建在所选对象之下；选中 **Canvas** 表示直接添加到场景中。
- **选择** —— 点击选中对象，**Ctrl + 单击** 可多选。属性检查器与场景编辑器窗口会同步跟随选择。
- **重命名** —— 双击名称、右键选择 **重命名（Rename）**，或直接修改属性面板里的 **Name** 一栏。
- **调整父子关系** —— 把对象拖到另一个对象，即可移动到该另一个对象的层级分支下。
- **删除** —— 选中对象后，按 **Delete** 键，或右键选择 **删除**。
- **剪切 / 复制 / 粘贴 / 创建副本** —— 右键菜单，或按下 **Ctrl + X**、**Ctrl + C**、**Ctrl + V**。

## 复制路径 / 名称 / UUID

右键对象，打开 **复制 路径 | 名称 | UUID** 子菜单，可以把对象的标识复制到剪贴板。脚本中需要获取某个对象时就会用到它们，例如 `get_object_by_path('Canvas/Player')`，`get_object_by_uuid('此处填入对象的UUID')`。
