场景和脚本准备好之后，就可以运行项目看看实际效果了。运行后会出现独立的游戏窗口，游戏中的日志输出可以在**控制台**窗口中查看。

## 启动运行

以下任一方式都能启动运行：
1. 点击**运行**按钮。[场景编辑器窗口](/zh-cn/editor_introduction/scene/)、[代码编辑器](/zh-cn/editor_introduction/code_editor/)、[积木编辑器](/zh-cn/editor_introduction/block_editor/)的工具栏上都有运行按钮；
2. 按 **Ctrl + R**快捷键；
3. 编辑器顶部菜单 **项目 → 运行** 
4. 右键资源管理器窗口中的**main.py → 运行**

:::note
运行的入口固定是项目根目录的 `main.py`：它负责加载场景并启动主循环，请不要删除或移动该文件（但是可以修改）。
:::

点击运行后，编辑器会自动先把当前场景进行保存，再启动游戏。游戏窗口会在一个独立的 Python 进程中运行，`.scene` 场景文件与脚本都从项目目录中读取，因此运行的永远是最新保存的内容（代码编辑器与积木编辑器在停止输入片刻后会自动保存）。

:::tip
若场景还未保存，首次运行代码时，会先弹出另存为窗口让用户保存场景。
:::

游戏运行期间，若开发者修改了场景内容或者脚本，游戏窗口是不会自动同步的。想要改动生效，关掉游戏窗口重新运行即可。

## 查看输出与报错

游戏里 `print()` 的内容和 Python 报错都会**实时**显示在[控制台](/zh-cn/editor_introduction/console/)窗口中。

脚本出错时，控制台里会显示完整的报错信息——**Ctrl + 单击**带 `File "…", line N` 的日志行，就能在[代码编辑器](/zh-cn/editor_introduction/code_editor/)中跳到出错的那一行。

## 常见问题

- **游戏窗口没有出现，或一闪而过？** 通常是脚本启动时就报错了，到控制台里看红色的错误日志。
- **改了代码，运行后没有变化？** 游戏运行时不会自动同步开发者在编辑器中做的修改，想要改动生效，关掉游戏窗口重新运行即可；改动也要已经保存（编辑器一般会自动保存，当然开发者也可以按下**Ctrl + S**手动进行保存）。
