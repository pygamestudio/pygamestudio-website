---
title: 属性检查器
---

窗口右侧的 **属性检查器（Inspector）** 用来显示当前选中对象的属性。

![属性面板](/images/doc/inspector_window.png)

## 工具栏

| 控件 | 作用 |
| --- | --- |
| **< / >** | 在最近选择过的对象之间前后切换，不影响场景内容。 |
| **分离** | 让属性检查器变成独立窗口，再次点击按钮或关闭独立窗口可停靠回来。|

未选中任何对象时属性检查器不显示内容。在[层级管理器](/zh-cn/editor_introduction/hierarchy/)中选中对象，或在[场景编辑器](/zh-cn/editor_introduction/scene/)中点击对象即可显示属性。

## 通用属性

| 属性行 | 含义 |
| --- | --- |
| **可见性** | 显示或隐藏对象。隐藏的对象不绘制，也不能被点击。 |
| **锚点** | 是对象缩放与旋转的中心，默认在**中心**位置。 |
| **名称** | 层级管理器中显示的名称。 |
| **位置** | X / Y 位置，相对于父对象。 |
| **大小** | 宽高（像素）。 |
| **缩放** | 拉伸对象，不改变大小数值。 |
| **角度** | 旋转角度。 |
| **颜色** | 填充颜色，带透明度通道 —— 点击色块打开取色器调整颜色与透明度。 |

不同对象类型还会额外显示各自的属性：

| 对象 | 额外属性 |
| --- | --- |
| **矩形** | 四个圆角。 |
| **多边形** | 多边形顶点。 |
| **线条** | 起点、终点、粗细。 |
| **文本** | 文本内容、字号、字体路径、粗体、斜体、下划线、删除线、水平对齐 / 垂直对齐。 |
| **图片** | 图片路径 —— 点击浏览按钮选择图片，或把图片文件拖到该属性上。 |
| **按钮 / 文本输入框 / 进度条 / 滑动条** | 标题、占位提示、进度、数值、范围与滑块手柄尺寸等。 |
| **粒子发射器 / 帧序列 / 瓦片地图** | 粒子参数、帧文件夹与帧率、图集与网格尺寸。 |

## 脚本路径

为对象挂载行为脚本：点击 **脚本** 一行的浏览按钮，选择项目中的 `.py` 文件；把文件拖到该行上效果相同。点击 **×** 按钮可取消挂载。

## 碰撞检测

除根节点 Canvas 外，每个对象都有 **开启碰撞** 属性：

| 属性行 | 含义 |
| --- | --- |
| **启用碰撞** | 是否对该对象启用碰撞检测。 |
| **碰撞形状** | 包围盒、矩形、椭圆、多边形。 |
| **碰撞偏移** / **碰撞大小** | 碰撞形状的偏移与尺寸大小。 |
| **碰撞顶点** | 多边形碰撞形状的顶点。 |

碰撞检测框会在场景编辑器窗口中以绿色描边预览，脚本中可用 `on_collision_enter(other)`、`on_collision_exit(other)` 响应碰撞开始与结束。

![启用碰撞](/images/doc/enable_collision.png)

## 物理系统

除根节点 Canvas 外，每个对象还可以拥有一个 **开启物理** 属性。勾选 **开启物理** 复选框后，对象会在游戏运行时进行物理模拟。

| 属性行 | 含义 |
| --- | --- |
| **开启物理** | 把对象变成刚体。 |
| **刚体类型** | 动态（会下落、被推动）、静态（永不移动、推动其他刚体）、运动学（由脚本移动，会带着站上去的对象）。 |
| **刚体形状** | 包围盒、矩形、椭圆、多边形。 |
| **形状偏移** / **形状大小** | 刚体形状的偏移与尺寸大小。 |
| **形状顶点** | 多边形刚体形状的顶点。 |
| **质量** | 质量越大越难推动（仅作用于动态刚体）。 |
| **固定旋转** | 让刚体保持直立，角色不会摔倒（仅作用于动态刚体）。 |
| **摩擦力** | `0` 像冰面，`1` 很黏。 |
| **弹性** | `0` 落地即停，`1` 完全弹回。 |
| **重力系数** | `0` 悬空、`1` 正常重力、负数向上升。 |
| **线性阻尼** / **角阻尼** | 移动与旋转减速的快慢。 |

开启物理后，所选对象的刚体形状会在场景编辑器窗口中以**紫色虚线**描边显示。

![启用物理](/images/doc/enable_physics.png)
