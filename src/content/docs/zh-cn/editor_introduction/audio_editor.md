---
title: 音频编辑器
---

**音频播放器（Audio Player）** 可以让你在编辑器里直接试听项目中的音频。在[资源管理器](/zh-cn/editor_introduction/asset/)中双击音频文件，它就会在窗口底部打开。

![音频播放器](/images/doc/audio_editor_window.png)

## 工具栏

| 控件 | 作用 |
| --- | --- |
| **打开音频文件** | 打开文件对话框（支持 `.wav`、`.mp3`、`.ogg`、`.flac`、`.aif`、`.aiff`、`.m4a`）。 注：`m4a`音频文件目前无法被编辑。|
| **保存 / 另存为** | 默认按原格式保存。 |
| **上一首 / 下一首** | 在项目文件夹中的音频文件之间切换。 |
| **播放 / 暂停** | 开始或暂停播放，按钮图标随播放状态变化。 |
| **停止** | 停止播放并回到开头。 |
| **分离** | 让音频编辑器变成独立窗口，再次点击按钮或关闭独立窗口可停靠回来。 |
| **删除选段 / 裁剪** | 删掉选中部分或只保留选中部分。 |
| **静音 / 增益** | 让选中部分静音或者按分贝调整音量（正数变大、负数变小）。 |
| **淡入 / 淡出** | 对选中部分（没选中就是整个音频文件）做音量渐入或渐出。 |
| **复制 / 粘贴** | 复制选中部分，在播放头处粘贴插入。 |
| **追加文件** | 把其它音频接在当前文件后面。 |
| **变速 / 变调** | 改播放速度（音调不变），或改音调（长短不变）。 |

未加载文件时，工具栏下方显示 **请选择一个音频文件**；加载文件后会显示音频的波形图。
