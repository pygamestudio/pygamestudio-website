---
title: 代码编辑器
---

**代码编辑器（Code Editor）** 是编辑器内置的文本编辑器，用来编写项目脚本和其它文本文件。在[资源管理器](/zh-cn/editor_introduction/asset/)中双击 `.py` 文件即可打开；点击[控制台](/zh-cn/editor_introduction/console/)里的报错日志也能直接跳转进来。

![代码编辑器](/images/doc/code_editor_window.png)

## 工具栏

| 控件 | 作用 |
| --- | --- |
| **文件名** | 当前打开的文件；名称前的 `*` 表示有未保存的修改。 |
| **缩小 / 放大** | 调整字号。 |
| **积木编辑器图标** | 把当前文件交给[积木编辑器](/zh-cn/editor_introduction/block_editor/)编辑。 |
| **运行** | 运行项目，等同于 **Ctrl + R**。 |
| **分离** | 让代码编辑器变成独立窗口，再次点击按钮或关闭独立窗口可停靠回来。 |

## 编辑功能

- 支持行号、语法高亮、撤销重做、剪切 / 复制 / 粘贴，这些操作在右键菜单中同样可用。
- **Tab** 用空格缩进，**Shift + Tab** 反缩进。
- **代码自动补全**：输入代码过程中会出现补全提示框，选择需要的提示即可。
- **自动保存**：停止输入 1.5 秒后自动保存；按下**Ctrl + S** 可手动保存。

## 保持同步

如果文件发生了变化 —— 例如被[积木编辑器](/zh-cn/editor_introduction/block_editor/)重新生成，或被外部编辑器保存 —— 打开中的编辑器会自动重新加载，保证你看到的始终是最新内容。
