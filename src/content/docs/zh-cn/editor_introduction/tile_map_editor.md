---
title: 瓦片地图编辑器
---

**瓦片地图编辑器（Tile Map Editor）** 用来绘制 **瓦片地图** 对象中的瓦片。在[层级管理器](/zh-cn/editor_introduction/hierarchy/)中双击瓦片地图对象即可打开，编辑器始终跟随当前选中的瓦片地图对象。

![瓦片地图编辑器](/images/doc/tile_map_editor_window.png)

## 工具栏

| 控件 | 作用 |
| --- | --- |
| **图集** | 选择存放瓦片的图片（点击浏览图标打开文件对话框）。 |
| **瓦片宽度 / 瓦片高度** | 图集中单个格子的尺寸。 |
| **列数 / 行数** | 地图的网格大小（单元格数量）。 |
| **画笔 / 橡皮 / 填充 / 取色** | 四种绘制工具。 |
| **缩小 / 放大 / 适应窗口** | 缩放画布；**适应窗口**按钮可显示完整地图。 |
| **分离** | 让瓦片地图编辑器变成独立窗口，再次点击按钮或关闭独立窗口可停靠回来。 |

工具栏下方的状态栏会显示地图尺寸以及图集中可用瓦片的数量；如果提示图集无法切出完整瓦片，说明瓦片尺寸与源图片的格子尺寸不一致。

## 图层

工具栏下方的图层栏用于管理地图图层：

| 控件 | 作用 |
| --- | --- |
| **图层列表** | 选择当前编辑、绘制的图层。 |
| **添加 / 删除 / 重命名** | 管理图层，地图至少保留一个图层。 |
| **眼睛图标** | 显示或隐藏当前图层。 |
| **碰撞** | 把该图层标记为碰撞层，该图层中画了瓦片的单元格在游戏里都是实心的。 |

图层自下而上依次绘制，上层会覆盖下层。建议地面用一个图层、装饰物用一个图层，再单独用一层放置玩家不能穿越的障碍。
