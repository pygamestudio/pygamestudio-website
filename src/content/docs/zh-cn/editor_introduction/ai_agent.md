---
title: AI 助手
---

**AI 助手**是编辑器内的一个聊天窗口。你用一句话描述想要的效果——比如“帮我创建一个矩形对象并挂上脚本”“为什么玩家会掉到地面下面？”——助手就会在你当前打开的项目工程里动手完成。

![AI助手](/images/doc/ai_agent_window.png)

## 与助手对话

| 控件 | 作用 |
| --- | --- |
| **输入框** | 输入需求后按 **回车** 发送（Shift + 回车键 换行）。 |
| **发送** | 与按 回车键 作用相同；按钮位于输入框内部右下角。 |
| **停止** | 中断正在生成的回答，之后可以继续发送新消息。 |
| **清空** | 清空当前对话。 |
| **设置** | 打开设置窗口，选择模型。 |

助手工作时，聊天记录下方的状态行会显示它正在做什么（`思考中…`、`调用 create_object…`、`等待你确认…`）。

## 助手能做什么

助手通过编辑器自身的命令读写当前工程：

| 方面 &nbsp;&nbsp; | 例子 |
| --- | --- |
| 工程 | 查看目录结构，读写 `.py` 脚本，新建文件。 |
| 场景 | 创建、查找、移动、缩放和删除对象，修改属性，读取层级结构。 |
| 游戏 | 运行与停止工程，读取日志输出。 |
| 资源 | 列出项目中的图片、声音和字体。 |
| 窗口 | 在积木编辑器里打开脚本并修改积木，在图片编辑器里绘制和保存，编辑瓦片地图的图层与格子，在音频播放器中打开并控制播放，还可以把任意窗口切换到最前。 |
| 构建 | 发起桌面端或网页端构建，查看进度，停止构建并打开输出目录。 |

助手的每一次改动都是编辑器里普通的可撤销操作：按 **Ctrl + Z** 就能逐步回退。

## 修改前的确认

在助手设置中勾选 **每次修改前先询问** 时，助手在改动工程前会先征求同意。取消勾选的话，助手会连续完成一系列改动；如果结果不满意，仍然可以用 **Ctrl + Z** 撤销。

| 按钮 | 效果 |
| --- | --- |
| **允许** | 该工具执行一次。 |
| **拒绝** | 跳过这次调用，助手会收到结果并继续下一步。 |

## 助手设置

点击窗口工具栏的齿轮按钮选择模型：

| 选项 | 需要填写 | 说明 |
| --- | --- | --- |
| **DeepSeek / OpenAI 模型** | 模型、密钥 | 接口地址会随模型名自动确定（`deepseek-flash`、`deepseek-v4-pro`、`gpt-4o-mini`），只需填入密钥。 |
| **本地模型（Ollama）** | 模型 | 先在本机运行 Ollama（`http://127.0.0.1:11434`），再填入已下载的模型名，无需密钥。 |
| **自定义（OpenAI 兼容）** | 请求地址、模型、密钥 | 用于其他任意 OpenAI 兼容接口。 |

密钥保存在本机的编辑器设置文件中，只会发送给你选择的接口地址。保存设置后会开始一段新的对话——因为新模型并不知道之前聊过什么。

步骤很多的复杂需求会在连续调用若干次工具后暂停：点**继续**让助手从停下的地方接着做，点**取消**则结束这一轮（对话会保留，下一条消息会开启新一轮）。

:::tip
把需求说小、说具体效果最好。遇到较大的功能，可以先让助手给出方案，再一步步执行。
:::
