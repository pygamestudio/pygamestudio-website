---
title: 场景编辑器
---

**场景编辑器（Scene）** 是编辑器中间面积最大的区域，用于搭建游戏画面：网格中央的矩形画布就是游戏窗口，可见对象都会绘制在它里面。

![场景窗口](/images/doc/scene_window.png)

## 工具栏

| 控件 | 作用 |
| --- | --- |
| **运行** | 运行项目，等同于 **Ctrl + R** 或菜单 **项目 → 运行**。 |
| **刷新** | 重新绘制预览；按住按钮不放可以持续刷新，方便边改边看。 |
| **分离** | 让场景编辑器变成独立窗口，再次点击按钮或关闭独立窗口可停靠回来。 |

场景有未保存修改时，标签页标题前会显示 `*`（保存请用 **Ctrl + S** 或 **文件 → 保存场景**）。

## 移动对象

选中对象后其左上角会出现 **拖拽控件（Gizmo）**，按住并拖动它即可移动对象；当对象与其它对象的边缘、中心对齐时，会出现品红色的**智能参考线**，让对象自动吸附成整齐的行列。多选时可以整体移动，属性检查器窗口中的 `位置` 数值会随拖动同步更新。需要精确数值时，直接在[属性检查器](/zh-cn/editor_introduction/inspector/)中填写。

## 视图操作

- **鼠标滚轮** —— 以指针为中心缩放视图（0.2× ~ 5×）。
- **按住鼠标中键拖动** —— 平移视图。

:::tip
给对象启用 `碰撞` 后，碰撞形状会以绿色描边叠加显示，方便一边搭场景一边确认碰撞判定范围；开启 `物理` 后，刚体形状则以紫色虚线显示。
:::

![启用物理](/images/doc/enable_physics.png)


## 运行项目

点击 **运行** 按钮后则会启动游戏窗口。游戏运行期间的所有输出都会实时显示在[控制台](/zh-cn/editor_introduction/console/)中；关闭游戏窗口即回到编辑器。
