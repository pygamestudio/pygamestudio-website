---
title: 控制台
---

窗口底部的 **控制台（Console）** 显示编辑器与运行中游戏的状态：项目消息、脚本输出，以及运行期间抛出的错误。

![控制台](/images/doc/console_window.png)

## 工具栏

| 控件 | 作用 |
| --- | --- |
| **清除** | 清空日志。 |
| **搜索** | 只显示包含输入关键字的日志行。 |
| **计数** | 信息、警告、错误三种级别的条数；点击旁边的复选框可在日志中显示或隐藏该级别日志。 |
| **分离** | 让控制台变成独立窗口，再次点击按钮或关闭独立窗口可停靠回来。 |

## 跳转到报错代码

把鼠标放到包含文件位置的报错日志行上，该行会出现下划线，此时 **Ctrl + 单击** 即可在[代码编辑器](/zh-cn/editor_introduction/code_editor/)中打开对应文件并跳转到该行。这是从报错定位到出错代码最快的方式。

![控制台点击报错跳转](/images/doc/console_click_error_line.png)
