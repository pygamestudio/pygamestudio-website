---
title: 项目管理器
---

**项目管理器（Dashboard）** 是启动 Pygame Studio 后首先出现的窗口，用于列出你已经创建或导入的所有项目，也是新建、重命名和删除项目的地方。

![项目管理面板](/images/doc/dashboard.png)

## 工具栏

| 控件 | 作用 |
| --- | --- |
| **创建** | 打开新建项目对话框。 |
| **导入** | 把本地已有的 Pygame Studio 项目添加进来。 |
| **搜索项目名称** | 根据名称搜索曾经创建或导入过的项目。 |
| **排序** | 按 **时间**、**名称** 或 **路径** 排列项目。 |

排序方式会被记住，下次打开编辑器时列表保持同样的顺序。

## 创建项目

点击 **创建**，在对话框中填写：

![创建对话框](/images/doc/create_dialog.png)

- **项目名称** —— 同时也是项目文件夹名，不能与已有文件夹重名。
- **项目路径** —— 项目的存放位置，点击 **浏览** 按钮选择文件夹。

点击 **创建** 后，项目会按默认目录结构生成（见[资源管理器](/zh-cn/editor_introduction/asset/)）并显示在列表中。

## 打开、重命名与删除

- **双击**项目即可在编辑器中打开；也可以右键选择 **打开**。
- 右键 → **重命名** 可以修改项目文件夹名称。
- 右键 → **删除** 会先弹出确认框，然后把项目文件夹移入回收站，操作失误仍可在回收站中恢复。
- 在空白处右键，可以进行 **创建** 和 **导入**。

![项目管理面板右键菜单](/images/doc/dashboard_menu.png)

:::tip
项目就是一个普通文件夹，编辑器所需的一切（包括 `main.py` 与 `project.pygs`）都在这个文件夹里。
:::
