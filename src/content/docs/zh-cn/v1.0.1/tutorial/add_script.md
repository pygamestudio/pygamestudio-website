---
title: 添加脚本
description: 在资源面板中创建 Python 脚本并挂载到矩形上，用代码或积木让它不断变大变小。
---

被添加到场景中的对象默认都是静止不动的，如果要让它们"动起来"，就需要用脚本来进行控制。本教程会给一个矩形对象挂上脚本，让它不断变大变小——第 4 步用代码手写实现，第 5 步用积木编辑器搭出同样的效果。

## 1. 创建对象

按照[创建一个对象](/zh-cn/tutorial/create_an_object/)中的步骤，向场景中添加一个**矩形**对象并选中它。属性窗口会显示它的各项属性。

## 2. 创建脚本文件

在**资源管理器**窗口中右键点击用于存放脚本的`script`文件夹，选择**添加 → 脚本**：

![资源面板中的添加 → 脚本](/images/doc/add_script_add_menu.png)

:::note
没有强制规定一定要将自定义脚本放到`script`文件夹中，创建到项目中其他位置也是可以的。
:::

脚本默认名为 `new.py`，我们可以将其重命名为 `big_small.py`。双击它可以打开[代码编辑器](/zh-cn/editor_introduction/code_editor/)。

![双击在代码编辑器中打开](/images/doc/add_script_double_click.png)

## 3. 把脚本挂载到矩形对象上

在场景中选中矩形对象，找到属性窗口中的 **脚本路径** 一行：点击浏览图标选择刚创建的文件（把 `.py` 文件拖到这一行上效果相同）。文件名会显示在该行中，点击旁边的 **×** 按钮即可取消挂载。

![已挂载脚本的 Script Path 一行](/images/doc/create_an_object_script_path.png)

:::tip
如果该行变成红色，说明引用的文件找不到了，通常是因为脚本在资源窗口中被移动或重命名。重新选择文件即可修复。
:::

## 4. 编写变大变小逻辑

双击脚本文件即可在代码编辑器中打开该脚本，用下面的代码替换模板主体：

```python
import pygamestudio as studio


class ObjectScript:
    def __init__(self, obj):                # 1
        self.obj = obj
        self.factor = 0.1                   # 2

    def on_update(self, dt):                # 3
        if self.obj.scale_x >= 5:           # 4
            self.factor = -0.1
        elif self.obj.scale_x <= 1:         # 4
            self.factor = 0.1

        self.obj.scale_x += self.factor     # 5
        self.obj.scale_y += self.factor
```

各部分的作用：

1. `__init__(self, obj)`：引擎会把对象交给脚本，把它保存在 `self.obj` 上，后面的回调就都能访问到它。 
2. `self.factor`：缩放因子，表示对象每次缩放时增加(或减少)的量。
3. `on_update(self, dt)`：游戏运行时每帧调用一次，`dt` 是本帧时长（秒）。
4. `if / else`：当对象的水平缩放属性`scale_x`大于等于`5`时，将`self.factor`设置为`-0.1`，表示要缩小对象。而当对象水平属性小于等于`1`时，将`self.factor`设置为`0.1`，表示要放大对象。 
5. `self.obj.scale_x += self.factor`：将对象的缩放属性`scale_x`和`scale_y`加上`self.factor`，当`self.factor`等于`-0.1`时，对象就会缩小，而当`self.factor`等于`0.1`时，对象就会变大。

![代码内容](/images/doc/script_content.png)

点击代码编辑器工具栏的**运行**按钮（或按 **Ctrl + R**）后，会看到矩形变大变小的效果。

:::tip
若场景还未保存，首次运行代码时，会先弹出另存为窗口让用户保存场景。
:::

## 5. 用积木编辑器实现同样的效果

不写代码也能搭出这套逻辑。再新建一个脚本（例如 `big_small_blocks.py`），把它拖到矩形的 **脚本路径** 一行上替换原脚本，然后在资源窗口中右键它，选择**在积木编辑器中打开**。

![在积木编辑器中打开](/images/doc/open_with_block_editor.png)

打开积木编辑器后，按照以下步骤依次执行：
1. 点击**变量**标签页，新建一个数值类型的变量，变量名填写为`factor`，初始值设置为`0.1`。
2. 点击**事件**标签页，展开矩形分支，将**每帧更新时(dt)**积木拖放到画布上。
3. 点击**控制**标签页，将**如果**积木拖放到画布上并进行拼接，选择属性`水平缩放`，判断条件选择`大于等于`，值设置为`5`。
4. 点击**动作**标签页，将**设置属性**积木拖入到**如果**积木块内，并将属性选择为`factor`，值设置为`-0.1`。
5. 点击**控制**标签页，将**否则如果**积木拖放到画布上并进行拼接，选择属性`水平缩放`，判断条件选择`小于等于`，值设置为`1`。
6. 点击**动作**标签页，将**设置属性**积木拖入到**否则如果**积木块内，并将属性选择为`factor`，值设置为`0.1`。
7. 点击**动作**标签页，将**2**个**属性增加**积木拖入到画布上并进行拼接，将它们的属性分别设置为`水平缩放`和`垂直缩放`，值设置为`factor`。

![积木拼接](/images/doc/code_with_block_editor.png)

确保矩形对象挂载了`big_small_blocks.py`脚本后，点击积木编辑器工具栏的**运行**按钮（或按 **Ctrl + R**）后，同样会看到矩形变大变小的效果。
