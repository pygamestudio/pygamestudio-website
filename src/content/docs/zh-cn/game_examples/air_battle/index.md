经典玩法的空战小游戏：你的飞机停在窗口底部，敌机从上方俯冲下来，击落一架得一分。三条命，难度会逐渐上升，结束后按 **Space** 再来一局。

将要完成的游戏：

| | |
| --- | --- |
| **目标** | 在三次被撞或被敌机溜走之前，击落尽可能多的敌机 |
| **操作** | **←** / **→** 飞行，**Space** 开火，结束后按 **Space** 重新开始 |
| **编辑器中的对象** | `Player`（多边形）、`Score`、`Lives` 与 `GameOver`（文本） |
| **脚本创建的对象** | `Bullet`（矩形）与 `Enemy`（多边形）——运行时动态创建与销毁 |
| **脚本** | 挂在画布上的一个总控脚本：`script/game.py` |

## 你将学到

- 用 `studio.create_object()` / `studio.destroy_object()` 动态创建与销毁对象
- 用 `collides_with_object()` 做逐帧碰撞判定
- 让一个总控脚本掌握整个游戏的运行状态
- 用 `dt` 写计时器：开火间隔、生成间隔与不断变短的延迟
