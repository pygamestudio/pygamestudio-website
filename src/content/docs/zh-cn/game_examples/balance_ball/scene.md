---
title: 搭建场景
description: 创建平衡球工程，并摆放平台、小球与两个文本标签。
---

整个游戏只需要四个对象：一块平台、一个球和两个标签。不需要图片、不需要音效，也不用下载任何素材。

## 1. 创建工程

按照[创建工程](/zh-cn/tutorial/create_a_project/)的步骤新建工程并打开它的场景。场景中已经有 **Canvas**，在[属性面板](/zh-cn/editor_introduction/inspector/)里给它一个深蓝色 **Color**，例如 `(14, 18, 30, 255)`。

窗口默认是 `800 x 600` 像素，下文所有坐标都基于这个尺寸。

## 2. 平台

添加一个**矩形**（[创建对象](/zh-cn/tutorial/create_an_object/)），按表格设置属性：

| 属性 | 值 |
| --- | --- |
| **Name** | `Platform` |
| **Pos** | `300`、`420` |
| **Size** | `200`、`16` |
| **Color** | `(120, 130, 150, 255)`——灰蓝色 |
| **圆角半径** | `8`（可选，四角同时设置） |

脚本稍后会通过 `set_angle()` 让它倾斜、用 `set_width()` 让它变窄，所以名字必须严格是 `Platform`。

## 3. 小球

添加一个**椭圆**：

| 属性 | 值 |
| --- | --- |
| **Name** | `Ball` |
| **Pos** | `380`、`380` |
| **Size** | `40`、`40` |
| **Color** | `(255, 150, 60, 255)`——橙色 |

## 4. 两个标签

用两个**文本**对象显示计时和结束提示：

| 对象 | 类型 | Pos | Size | Text | Color | 可见性 |
| --- | --- | --- | --- | --- | --- | --- |
| `Score` | 文本 | `200`、`20` | `400`、`40` | `Time: 0.0s` | 白色 | 开 |
| `GameOver` | 文本 | `200`、`250` | `400`、`60` | `Press Space` | `(255, 220, 80, 255)` | **关** |

文本会在自己的矩形内居中绘制，因此两个标签都正好位于画布中央。把 `GameOver` 的 **Visibility** 取消勾选——脚本会在小球掉落时再显示它。

## 5. 检查并保存

- [层级面板](/zh-cn/editor_introduction/hierarchy/)中应能看到 `Platform`、`Ball`、`Score` 与 `GameOver` 位于 `Canvas` 之下。
- **所有对象都不需要开启碰撞**：这个游戏只用坐标比较，不需要碰撞形状。
- 按 **Ctrl + S** 保存场景。

下一步：[小球脚本](/zh-cn/game_examples/balance_ball/script/)会把这个静态场景变成真正的游戏。
