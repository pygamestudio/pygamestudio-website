---
title: 平衡球
description: 让小球一直停在一块不断倾斜、不断变小的平台上——一个关于移动、反馈与重新开始的小游戏。
---

小球站在一块平台上。按 **←** / **→** 让平台倾斜，小球就会向另一侧滚动；随机的阵风，加上每秒钟都在变窄的平台，让坚持变得越来越难。小球一旦滚出边缘就会掉出窗口，本轮结束。

将要完成的游戏：

| | |
| --- | --- |
| **目标** | 尽可能久地把小球留在平台上 |
| **操作** | **←** / **→** 倾斜平台，**Space** 在掉落之后重新开始 |
| **对象** | `Platform`（矩形）、`Ball`（椭圆）、`Score` 与 `GameOver`（文本） |
| **脚本** | 一个挂在球上的脚本：`script/ball.py` |
| **你将学到** | 与帧率无关的移动（`dt`）、键盘输入、文本更新、一个小状态机 |
