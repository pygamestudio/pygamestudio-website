经典数字拼图的小型版本：十六个格子，方向键让全部数字朝一个方向滑动，相同的数字合并成更大的数字，每次合并都加分。到达 2048——或者至少在无路可走之前让这一局撑得更久。

将要完成的游戏：

| | |
| --- | --- |
| **目标** | 合并相同的数字；每次合并得分，棋盘填满且相邻数字都不再相同时结束 |
| **操作** | **←** / **→** / **↑** / **↓** 滑动棋盘，结束后按 **Space** 重新开始 |
| **编辑器中的对象** | `Board`（矩形）与 `Title`、`Score`、`Hint`（文本） |
| **脚本创建的对象** | 16 个格块（`Tile0`～`Tile15` 与叠在上面的 `Num0`～`Num15`）以及结束遮罩 |
| **脚本** | 挂在画布上的一个总控脚本：`script/game.py` |

## 你将学到

- 用纯 Python 保存游戏状态（`self.grid` 中的 16 个数字），再让对象照着它绘制
- 用 `for` 循环一次性创建整块棋盘的矩形与文本
- 让按键“按一次动一步”，而不是按住时每帧都在动
- 按行处理的核心算法：滑动、合并与计分
- 用数值决定外观：不同数字颜色不同、数字越长字体越小
