**Pygame Studio** is a visual 2D game engine built with **PyGame-ce** and **PySide6**.
It aims to fill the gap of lacking a professional visual game engine in Python, lower the barrier of game development, and help Python developers and beginners easily create their own 2D games.

Every contribution keeps this project updated, improves features, optimizes user experience, and lets more people enjoy game creation.
