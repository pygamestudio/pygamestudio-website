---
title: Objects
description: Every scene object type with its type key and the page documenting its properties, methods and events.
---

| Object | Type key | What it is |
| --- | --- | --- |
| [Canvas](/api/objects/canvas/) | `CANVAS` | The root of a scene; moving it moves everything. |
| [Rect](/api/objects/rect/) | `RECT` | Filled rectangle with optionally rounded corners. |
| [Ellipse](/api/objects/ellipse/) | `ELLIPSE` | Ellipse (width = height for a circle). |
| [Line](/api/objects/line/) | `LINE` | Straight line between two points. |
| [Polygon](/api/objects/polygon/) | `POLYGON` | Free shape from a list of points. |
| [Image](/api/objects/image/) | `IMAGE` | Picture from the asset panel, tintable. |
| [Text](/api/objects/text/) | `TEXT` | Label drawn with a font. |
| [Button](/api/objects/button/) | `BUTTON` | Clickable rectangle or image. |
| [Text Input](/api/objects/text_input/) | `TEXT_INPUT` | Editable input box. |
| [Progress Bar](/api/objects/progress_bar/) | `PROGRESS_BAR` | 0–100 % indicator. |
| [Slider](/api/objects/slider/) | `SLIDER` | Draggable value control. |
| [Particle](/api/objects/particle/) | `PARTICLE` | Emitter for sparks, smoke and explosions. |
| [Frame Sequence](/api/objects/frame_sequence/) | `FRAME_SEQUENCE` | Image-by-image animation. |
| [Tile Map](/api/objects/tile_map/) | `TILE_MAP` | Level built from a tileset image. |
